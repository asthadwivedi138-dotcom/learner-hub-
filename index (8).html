📚 2. Notes - Web Technology

📘 Web Technology Notes (Topics 1-24) ▼

1. Introduction to Web Technology

Web technology covers the tools and standards used to build and deliver websites and web applications. The main building blocks are HTML for structure, CSS for presentation, and JavaScript for behavior, supported by browsers, servers, and protocols such as HTTP.

2. HTML Basics

HTML (HyperText Markup Language) describes the structure of a web page using elements written as tags. Every page has a document type declaration, an html element, a head and a body.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Page</title>
</head>
<body>
    <h1>Hello</h1>
    <p>This is a paragraph.</p>
    <a href="https://example.com">A link</a>
</body>
</html>

3. HTML Forms and Tables

Forms collect user input using elements such as input, select, textarea and button. Tables display tabular data using table, tr, th and td.

<form action="/register" method="post">
    <label for="name">Name</label>
    <input type="text" id="name" name="name" required>
    <button type="submit">Submit</button>
</form>

<table>
    <tr><th>Course</th><th>Credits</th></tr>
    <tr><td>Python</td><td>4</td></tr>
</table>

4. CSS Basics

CSS (Cascading Style Sheets) controls colors, fonts, spacing and layout. CSS can be applied inline, in a style element, or from an external stylesheet, which is the recommended approach for larger sites.

body { font-family: Arial, sans-serif; background: #f5f5f5; }
h1   { color: navy; text-align: center; }

5. CSS Selectors and Box Model

Selectors choose which elements to style: element (p), class (.card), id (#menu), and combinations. The box model describes how every element is made of content, padding, border and margin.

.card {
    width: 300px;
    padding: 16px;
    border: 1px solid #ccc;
    margin: 10px;
    box-sizing: border-box;
}

6. CSS Flexbox

Flexbox is a one-dimensional layout system for arranging items in a row or column, with control over alignment, spacing and wrapping.

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 12px;
}

7. CSS Grid

CSS Grid is a two-dimensional layout system that arranges content in rows and columns. It is well suited to dashboards and card layouts.

.dashboard {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 16px;
}

8. Introduction to JavaScript

JavaScript is the programming language of the browser. It adds behavior to pages: reacting to clicks, validating forms, updating content and communicating with servers. It can also run on servers using Node.js.

<script>
    console.log("Hello from JavaScript");
</script>

9. Variables and Data Types

Variables are declared with let (changeable) or const (not reassignable). Common data types are string, number, boolean, null, undefined, object and array.

const course = "Python";
let students = 40;
let active = true;
const topics = ["Basics", "OOP", "Files"];

10. Operators and Conditions

Operators perform calculations and comparisons. Prefer strict equality (===) to avoid unexpected type conversion. Conditions use if, else if, else and switch.

let marks = 72;
if (marks >= 75) {
    console.log("Distinction");
} else if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

11. Loops

Loops repeat a block of code. Common forms are for, while, do...while and for...of.

const courses = ["C", "Python", "Java"];
for (const c of courses) {
    console.log(c);
}

12. Functions

A function is a reusable block of code. JavaScript supports function declarations, function expressions and arrow functions.

function greet(name) {
    return "Hello, " + name;
}
const square = n => n * n;
console.log(greet("Astha"), square(5));

13. Arrays and Objects

Arrays store ordered lists of values; objects store key-value pairs. Methods like map, filter and forEach make working with arrays concise.

const student = { id: 1, name: "Astha", courses: ["C", "Python"] };
const upper = student.courses.map(c => c.toUpperCase());
console.log(upper);

14. DOM Manipulation

The Document Object Model (DOM) represents an HTML page as a tree of objects. JavaScript can read and change elements, attributes, styles and text through this tree.

<p id="msg">Click the button</p>
<button id="btn">Click Me</button>

<script>
document.getElementById("btn").addEventListener("click", function() {
    document.getElementById("msg").textContent =
        "Welcome to LearnHub!";
});
</script>

When the button is clicked, JavaScript finds the paragraph and changes its text. DOM manipulation is useful for interactive dashboards, expandable notes, menus, form feedback, and dynamically updated course lists.

15. JavaScript Events and Form Validation

An event is an action or occurrence that a browser can detect. Examples include clicking a button, typing into a field, submitting a form, loading a page, or changing a selected value. JavaScript event handlers allow a website to respond to these actions.

Form validation checks whether submitted information follows the expected rules. For example, a registration form may require a name, a valid email address, and a password of sufficient length. HTML attributes such as required, type="email", and minlength can provide basic browser validation, while JavaScript can implement additional checks.

<form id="loginForm">
    <input id="email" type="email"
           placeholder="Enter email" required>
    <button type="submit">Login</button>
</form>

<script>
document.getElementById("loginForm").addEventListener("submit", function(event) {
    event.preventDefault();

    const email = document.getElementById("email").value;

    if (email.trim() === "") {
        alert("Please enter your email");
    } else {
        alert("Form submitted for validation");
    }
});
</script>

The preventDefault() method stops the form's normal submission so the script can perform its own checks. Client-side validation improves usability, but it is not a substitute for server-side validation because users can bypass browser checks.

16. Responsive Web Design

Responsive Web Design is an approach in which a website adjusts its layout and content to different screen sizes and devices. A responsive page should remain usable on mobile phones, tablets, laptops, and desktop computers.

Responsive design commonly uses flexible layouts, relative units, responsive images, and CSS media queries. The viewport meta tag helps mobile browsers display pages at the device's actual width instead of using a wider virtual layout.

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

<style>
.course-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

@media (max-width: 768px) {
    .course-grid {
        grid-template-columns: 1fr;
    }
}
</style>

In this example, the course grid displays three columns on wider screens and one column when the viewport is 768 pixels wide or narrower. Responsive layouts improve readability, navigation, and usability across devices.

17. Web Browsers and Web Servers

A web browser is software used to request, retrieve, and display web content. Examples include Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari. A browser interprets HTML, CSS, and JavaScript to render an interactive page for the user.

A web server is a system or software that receives HTTP requests and sends responses. The response may contain an HTML page, an image, a stylesheet, JavaScript, or data in a format such as JSON. Web servers can also forward requests to application code that accesses databases or performs business logic.

For example, when a student opens an online learning website, the browser sends a request to the server. The server returns the requested page or data, and the browser renders the content. Some content may be generated dynamically based on the user's account or selected course.

18. HTTP and HTTPS

HTTP stands for HyperText Transfer Protocol. It defines how web clients and servers exchange requests and responses. A request may ask for a page, submit form information, or retrieve data from an API. A response contains a status code and may include the requested content.

HTTPS is HTTP protected by TLS encryption. It helps protect data while it travels between a browser and a server, verifies the server's identity through its certificate, and helps detect unauthorized changes to transmitted data.

Common HTTP methods include GET for retrieving information, POST for submitting data, PUT or PATCH for updating resources, and DELETE for requesting resource removal. Common status codes include 200 for success, 404 for a resource not found, and 500 for a server error.

Websites that handle login details, personal information, or payments should use HTTPS. However, HTTPS alone does not guarantee that a website is trustworthy or that its application is free from security vulnerabilities.

19. Client-Side and Server-Side Development

Client-side development refers to code that runs in the user's browser. HTML, CSS, and browser JavaScript are commonly used to build the interface, respond to interactions, and display data. Client-side code can improve responsiveness because some actions can happen without a full page reload.

Server-side development refers to code that runs on a server. It can authenticate users, apply business rules, validate submitted data, communicate with databases, and return pages or API responses. Common server-side technologies include Python, Java, PHP, JavaScript with Node.js, and others.

For an online learning management system, the client side may display courses and notes, while the server side verifies a user's account, stores course progress, and retrieves saved information from a database. Many modern applications combine both approaches.

Security-sensitive logic and access checks must be enforced on the server. Hiding a button in the browser does not prevent a user from attempting the underlying action directly.

20. Web APIs and Fetch API

An API, or Application Programming Interface, defines how different software components communicate. A web API allows a browser or another application to request data or perform operations on a server. APIs often exchange data in JSON format.

The Fetch API is a browser feature used to make HTTP requests from JavaScript. It returns a Promise, allowing the program to handle responses asynchronously. Developers commonly check whether a response was successful, convert JSON response data, and handle errors.

fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(response => {
        if (!response.ok) {
            throw new Error("Request failed");
        }
        return response.json();
    })
    .then(data => {
        console.log(data.title);
    })
    .catch(error => {
        console.error("Error:", error);
    });

This example requests a sample post, checks the response, converts it into a JavaScript object, and prints its title. Real applications should handle network failures, loading states, permissions, and invalid responses appropriately.

21. Local Storage and Session Storage

Web Storage allows a browser to store small amounts of key-value data for a website. Local Storage generally keeps data until it is removed, while Session Storage is associated with a particular browser tab session and is normally cleared when that session ends.

Both APIs store values as strings. Objects can be converted to JSON before saving and parsed when retrieved. These storage mechanisms are useful for preferences, temporary interface state, and simple client-side settings.

localStorage.setItem("theme", "dark");

const selectedTheme = localStorage.getItem("theme");
console.log(selectedTheme);

sessionStorage.setItem("currentCourse", "Python");

const course = sessionStorage.getItem("currentCourse");
console.log(course);

Local Storage and Session Storage are not secure databases and should not be used to store passwords or sensitive secrets. Client-side data can be read or modified by scripts running on the same origin, so applications must consider security and privacy carefully.

22. Website Security Basics

Website security involves protecting users, data, and services against unauthorized access and malicious activity. Security is important for websites that process login information, student records, payments, or personal details.

  • HTTPS: Protects information transmitted between the browser and server using TLS.
  • Authentication: Verifies a user's identity, commonly through a login system.
  • Authorization: Determines which resources and actions an authenticated user is allowed to access.
  • Input validation: Checks submitted information for expected types, formats, and limits.
  • Output encoding: Helps prevent untrusted content from being interpreted as executable HTML or script.
  • Secure password storage: Passwords should be stored using appropriate password-hashing methods rather than plain text.
  • Access control: Sensitive actions and data must be protected by server-side permission checks.

Security requires multiple layers of protection. Developers should keep software updated, handle errors carefully, limit access to sensitive information, and test their applications for common vulnerabilities.

23. Accessibility in Web Development

Web accessibility means designing websites so that people with different abilities can use them. This includes users who rely on keyboards, screen readers, magnification, captions, or other assistive technologies.

Accessible websites use meaningful headings, labels for form controls, alternative text for informative images, readable color contrast, and clear navigation. Interactive components should support keyboard use and provide understandable focus indicators.

<label for="studentEmail">Email Address</label>
<input
    type="email"
    id="studentEmail"
    name="email"
    required
>

<img src="course.jpg"
     alt="Students learning in a classroom">

The label connects the text to the email input, and the alt attribute provides a text alternative for the image. Accessibility benefits many users and improves the overall usability of a website.

24. Advantages and Applications of Web Technology

Web technology has transformed how people access information, communicate, learn, and conduct business. Websites and web applications can be accessed from different devices through a browser, reducing the need to install separate applications for every platform.

  • Education: Learning management systems provide online courses, notes, assignments, quizzes, and progress tracking.
  • Business: Companies use web applications for customer service, inventory, sales, and internal operations.
  • Communication: Web technologies support email, messaging, video meetings, and collaboration tools.
  • E-commerce: Online stores display products, manage shopping carts, and process orders.
  • Healthcare: Web applications can support appointment scheduling and access to authorized information.
  • Government services: Websites allow users to access forms, information, and digital services.
  • Entertainment: Streaming services, online games, and digital media platforms use web technologies.

Web technology makes information sharing and service delivery more convenient. Successful web applications still require reliable hosting, good performance, accessibility, security, maintenance, and a user-friendly design.
